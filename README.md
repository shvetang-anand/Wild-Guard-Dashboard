# WildGuard 🐾
### Wildlife Conservation Dashboard

WildGuard is a student-built wildlife conservation dashboard focused on selected species in Kerala and Andhra Pradesh, India.

## 🌿 Features

- **Species Explorer:** Browse six wildlife species with scientific names, habitats, and conservation statuses.
- **Search and Filters:** Filter species by state, conservation status, habitat, or threats.
- **Threat Overview:** Visualize threats recorded in the selected species profiles.
- **Conservation Status Chart:** Compare global IUCN categories for the displayed species.
- **AI Conservation Assistant:** Ask questions about wildlife conservation and possible conservation actions.
- **Source References:** Access conservation references and wildlife image credits.

## 🐘 Species Covered

### Kerala
- Nilgiri tahr (*Nilgiritragus hylocrius*)
- Lion-tailed macaque (*Macaca silenus*)
- Asian elephant (*Elephas maximus*)

### Andhra Pradesh
- Jerdon's courser (*Rhinoptilus bitorquatus*)
- Yellow-throated bulbul (*Pycnonotus xantholaemus*)
- Indian pangolin (*Manis crassicaudata*)

## 🛠️ Technologies

- HTML and CSS
- JavaScript
- Node.js
- AI API integration through a backend

## 🚀 Running Locally

1. Install Node.js.
2. Clone or download this repository.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file locally and add the API key required by the backend.
5. Start the application using the start script defined in `package.json`.
6. Open the local address printed by the server in your browser.

**Security:** Never commit `.env` or expose private API keys in browser code.

## 📚 Data and Accuracy

Conservation categories refer to global assessments unless stated otherwise. Threat counts represent tags assigned to the displayed profiles; they are not measurements of statewide threat prevalence. The six profiles are a selected sample, not a complete inventory of wildlife in either state.

AI-generated responses should be checked against reliable conservation sources. Please consult the linked references for assessment dates, population estimates, and image licences.
